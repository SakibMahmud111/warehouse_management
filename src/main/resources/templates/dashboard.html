How the planning features work together

  1. F1 Demand forecasting predicts this winter's length from temperatures and learns each product's weekly sales (winter products sell more on cold days; Eid weeks get an uplift). The regressions are trained in Python with scikit-learn.
  2. F2 Safety stock uses the F1 forecast, its error and the supplier's lead time to size the buffer that protects against running out.

Everything is recalculated automatically whenever sales, temperatures, products or settings change.
